SETUP STEPS
================================================================================

STEP 1: Create .env file
  cd server
  nano .env  (or your editor)

STEP 2: Copy template above

STEP 3: Update values:
  - DATABASE_URL: Your database connection
  - JWT_SECRET: Generate strong secret
  - SUPER_ADMIN_EMAIL: Your email
  - SUPER_ADMIN_PASSWORD: Your password

STEP 4: Save file

STEP 5: Start server
  npm run dev

STEP 6: Check output
  Prime Attendance on port 7788
  Super admin: admin@yourdomain.com

================================================================================
VARIABLE DETAILS
================================================================================

DATABASE_URL
  Format: postgresql://USERNAME:PASSWORD@HOST:PORT/DATABASE
  Example: postgresql://prime:prime_secret@localhost:5432/prime_attendance
  Required: YES

PORT
  Server port number
  Default: 7788
  Device uses: Device Menu → Cloud Server → Port: 7788

TZ (Timezone)
  Asia/Dhaka, Asia/Kolkata, UTC, etc.
  Default: Asia/Dhaka
  Important: Match device timezone

NODE_ENV
  development or production
  Default: development
  Production: Optimized, minimal logs

JWT_SECRET
  JWT signing secret
  Min: 32 characters
  Generate: openssl rand -base64 32
  Required: YES
  Important: Change in production!

JWT_EXPIRES_IN
  Token expiration: 1h, 24h, 7d, 30d
  Default: 7d

SUPER_ADMIN_EMAIL
  First super admin email
  Default: admin@primetechbd.xyz
  Can change later in UI

SUPER_ADMIN_PASSWORD
  First super admin password
  Min: 8 characters
  Default: Admin@12345
  Change after first login!

SUPER_ADMIN_NAME
  First super admin name
  Default: Super Admin

ERPNEXT_ENABLED
  Enable ERPNext integration
  Default: false
  Set to true if using ERPNext

CLIENT_DIST_PATH
  Production client build path
  Default: ../../client/dist
  EasyPanel: /app/client-dist

CORS_ORIGIN
  Allowed origin for CORS
  Local: http://localhost:5173
  Production: https://yourdomain.com

================================================================================
COMMON ISSUES
================================================================================

Issue: DATABASE_URL is required
  → Check .env file exists
  → Check DATABASE_URL is set
  → Restart server

Issue: JWT_SECRET must be at least 32 characters
  → Generate: openssl rand -base64 32
  → Update JWT_SECRET in .env
  → Restart server

Issue: Cannot connect to database
  → Check DATABASE_URL is correct
  → Check PostgreSQL is running
  → Check credentials

Issue: Port already in use
  → Use different port: PORT=7789
  → Or kill existing process: lsof -i :7788

Issue: Login fails
  → Check SUPER_ADMIN_EMAIL
  → Check SUPER_ADMIN_PASSWORD
  → Reset database: npx prisma migrate reset
