10 MAJOR FEATURE MODULES
─────────────────────────────────────────────────────────────────────────────────

1. ATTENDANCE MANAGEMENT
   • Real-time punch collection from ZKTeco devices
   • Auto status calculation (Present/Absent/Leave/OT)
   • Late/early detection with grace period
   • Missing punch detection & alerts
   • Attendance regularization requests

2. SHIFT & ROSTER MANAGEMENT
   • 4 shift types: Fixed, Flexible, Rotational, Auto
   • Employee/department assignment
   • Weekly off configuration
   • Shift change requests
   • Monthly roster view

3. OVERTIME MANAGEMENT
   • Auto OT calculation (18:00-22:00 = 1.5x, >22:00 = 2x)
   • Manual OT claims
   • Manager approval workflow
   • Weekly OT aggregation
   • Holiday OT multipliers

4. EMPLOYEE SELF SERVICE (ESS)
   • View attendance history & stats
   • Apply for leave online
   • Submit OT requests
   • Request punch corrections
   • Track all submissions

5. LEAVE MANAGEMENT
   • Multiple leave types (Casual, Sick, Annual, Special)
   • Balance tracking (credited, used, available)
   • Application workflow
   • Manager approval
   • Carry-over & encroachment rules

6. PAYROLL INTEGRATION
   • Attendance data export (CSV, Excel, PDF)
   • Salary calculation support
   • WPS Report (Middle East)
   • ERPNext API integration
   • Daily rate calculation

7. DEVICE MANAGEMENT
   • Remote device monitoring
   • Device online/offline status
   • Remote commands (Reboot, Time Sync, User Sync)
   • Biometric & card sync tracking
   • Firmware updates
   • Bulk device operations

8. APPROVAL WORKFLOWS
   • Leave approval chain
   • OT approval workflow
   • Attendance correction approval
   • Multi-level support (sequential & parallel)
   • Timeout escalation
   • Email notifications
   • Complete audit trail

9. COMPREHENSIVE REPORTING
   • Daily attendance report
   • Monthly summary
   • Late/absent reports
   • OT report
   • Leave report
   • Employee movement history
   • Custom reports
   • Scheduled email delivery

10. MULTI-BRANCH SUPPORT
    • Multiple companies & locations
    • Department hierarchy
    • 1000+ employees tested
    • 100+ devices simultaneously
    • Branch-aware reporting
    • Scalable architecture

KEY DECISION POINTS
─────────────────────────────────────────────────────────────────────────────────

1. Database Architecture
   ☐ Multi-tenant isolation (decided: DB-level + app-level filtering)
   ☐ Single vs. multiple databases (decided: single DB per deployment)

2. Approval Strategy
   ☐ Sequential vs. parallel (decided: configurable per workflow)
   ☐ Timeout escalation (decided: auto-escalate to HR after N days)

3. OT Calculation
   ☐ Fixed rates vs. configurable (decided: configurable per organization)
   ☐ Weekly aggregation (decided: UTC-based weeks)

4. Reporting
   ☐ Real-time vs. batch (decided: batch aggregation nightly)
   ☐ Export formats (decided: CSV, Excel, PDF)

5. Device Commands
   ☐ Immediate vs. queued (decided: queued for reliability)
   ☐ Poll-based vs. push (decided: poll-based for 99% ZKTeco devices)


KNOWN CHALLENGES & SOLUTIONS
─────────────────────────────────────────────────────────────────────────────────

Challenge 1: Attendance Status Calculation Complexity
  Solution: Comprehensive test cases, service layer abstraction

Challenge 2: Multi-Tenant Data Isolation
  Solution: Tenant context in JWT, filtering on all queries, database unique constraints

Challenge 3: Large Dataset Performance (1000+ employees)
  Solution: Proper indexing, pagination, nightly aggregation, caching

Challenge 4: Approval Workflow Flexibility
  Solution: Configuration-driven, recursive approval chain logic

Challenge 5: Email Delivery Reliability
  Solution: Retry logic, queue system, detailed logging

Challenge 6: Device Command Reliability
  Solution: Queueing, retry logic, timeout handling, fallback options
