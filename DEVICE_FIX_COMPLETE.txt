TROUBLESHOOTING
================================================================================

If device still shows offline:

1. Check server logs:
   npm run dev
   Look for: [iclock] Device connected: SN=...

2. Run debug script:
   ./scripts/debug-device.sh http://185.250.37.21:7788 SN

3. Check database:
   npx prisma studio
   Device table → lastSeenAt timestamp

4. Check device configuration:
   Device menu → Comm → Cloud Server
   - Enable: ON
   - IP: 185.250.37.21
   - Port: 7788
   - HTTPS: OFF

5. Check firewall:
   sudo ufw allow 7788/tcp

6. Check network:
   ping 185.250.37.21
   nc -zv 185.250.37.21 7788
